# Implementation Reports

The report archive preserves historical evidence without rewriting it to match later outcomes.

- [`prompt-implementation-reports/INDEX.md`](prompt-implementation-reports/INDEX.md) records report availability for every prompt.
- [`prompt-implementation-reports/exact/`](prompt-implementation-reports/exact/) contains verbatim assistant completion messages recovered from the preserved Prompt 23–25D Codex session.
- [`prompt-implementation-reports/025E-implementation-report.md`](prompt-implementation-reports/025E-implementation-report.md) records this consolidation milestone.

Historical report paths, command outputs, and limitations are preserved as written even when a later prompt superseded the visual result. Use the prompt ledger’s supersession links to find current authority.
