# Scope Boundaries

## Current production scope through Prompt 27A

- Modular 2D segmented characters.
- Front and canonical-side presentation with stable gameplay-facing
  authority.
- Male/female body presets and bounded morphology.
- Independent anatomy, hair, permanent base-presentation modesty surfaces,
  removable clothing, and equipment.
- Image-backed art packs and atlas resources.
- Modular equipment items, bounded visual recipes, outfit presets, and custom
  recombination.
- Deterministic animation, character physics, interaction coordination, IK,
  deformation, and secondary motion.
- Semantic visual-geometry validation and real D3D12/DXIL evidence.
- Two preloaded layered environment themes over one authoritative collision
  world.
- Collision-derived white standable surfaces, decorative non-collision
  environment art, parallax, debug separation, and allocation-free theme
  switching.
- One integrated production `foundation` route combining two accepted
  characters, current wardrobe, environment themes, traversal, three
  data-declared fixed-root handshakes, view-aware presentation,
  participant-qualified equipment ordering, reset, and bounded rendering.
- One state-conditioned evidence harness with 16 ordered D3D12 captures,
  fail-closed metadata, a bounded read-only HUD, deterministic review
  packaging, and repeatability evidence. Manual aesthetics remain pending.

## Possible next product scope

One narrow gameplay vertical slice may add:

- a beginning;
- traversal;
- an objective or meaningful interaction;
- a completion condition;
- replay/reset.

Prompt 27A does not implement that gameplay loop, and this document does not
authorize Prompt 27B, Prompt 28, or any unrelated later work.

## Later tools

- Character/body editor.
- Wardrobe/garment/outfit editor.
- Level/theme editor.
- Mission/objective editor.

These tools must export the same production definitions consumed by the
runtime and validators. They must not introduce an editor-only skeleton,
collider, garment-fit model, layer model, environment-theme identity,
interaction identity, or atlas identity system.

## Deferred general-engine features

- Runtime 3D or 3D-to-2D generation.
- Arbitrary 360-degree character rotation.
- General cloth simulation or clothing collision.
- Arbitrary full-body paired-pose solving.
- Multi-contact carrying/lifting without a separately authorized root
  constraint.
- Universal game-editor suite.
- Unrestricted scripting ecosystem.
- Broad combat/enemy framework.
- Inventory economy.
- Dialogue framework.
- Save-game platform.
- Networking.
- Weather, liquids, or unrelated world simulation.

## Binding rule

Future extensibility is a documentation and schema-design constraint, not
permission to implement speculative systems. A runtime extension belongs in a
milestone only when accepted production content or the immediately following
authorized milestone needs it and the existing authority cannot represent it.
