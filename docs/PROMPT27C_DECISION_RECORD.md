# Prompt 27C Engineering Decision Record

## Status and scope

Prompt 27B is the inherited automated baseline at HEAD
`3259f79db18659746ca97bde96456da086a40126`. Prompt 27A and Prompt 27B
owner/manual visual acceptance remain `[PENDING OWNER REVIEW]`.

Prompt 27C is limited to production male/female base-anatomy silhouette,
proportion, joint continuity, the corresponding semantic visual-geometry
ruler, and anatomy evidence. It does not change locomotion clips, garment
schemas or conversion, handshake behavior, collision authority, the Prompt
27B camera/framing/parallax policy, either resize fixture, or the established
16-pixel world-camera bound.

All Prompt 27, Prompt 27A, and final Prompt 27B evidence is immutable.
Prompt 27C writes only beneath `zig-out/p27c_evidence`.

## Pre-correction empirical declaration

This declaration is frozen before any Prompt 27C production art, authored
size, pivot, rest rotation, or presentation correction.

### Measurement method

The anatomy ruler consumes the actual production `visual_geometry.Trace`
generated by `character_art.submitTraced`, the decoded production RGBA pages,
and the deterministic acceptance camera. It measures:

- semantic joint endpoints after the production sprite transform;
- alpha-visible cross sections sampled perpendicular to the transformed limb
  axis;
- alpha-derived shoulder top contours and contour curvature;
- style/view-specific body-part spans and ratios;
- source-pixel dark transverse edge coverage at articulated ends;
- transformed foot forward axes and neutral-front bilateral stance;
- existing pixel-space gap/overlap continuity from Prompt 25D.

The D3D12 route uses the existing SDL3 GPU renderer, global
`UnifiedRenderQueue`, and readback path. Clean frames are measured separately
from semantic traces; debug landmarks and rulers are appended only after a
clean prepared queue exists.

Missing pages, empty alpha, missing landmarks, degenerate axes, nonfinite
values, missing matrix cases, or unreadable D3D12 frames fail closed.

### Required matrix

The pre-correction and final reports enumerate:

- both production styles;
- front, side-right, and side-left;
- neutral, relaxed-arm, extended-arm, bent-elbow, deep-knee-bend, and grounded
  standing samples where applicable;
- global build `15`, `50`, and `85`;
- morphology channel values `20` and `80` for `shoulder_width`,
  `torso_width`, `upper_arm_thickness`, `thigh_thickness`, and
  `calf_thickness`;
- body-only `base_only` presentation;
- both semantic sides independently.

The D3D12 evidence matrix contains male/female front, side-left, side-right,
relaxed arm, extended arm, bent elbow, deep knee bend, neutral standing, and
declared morphology extremes. Close-up sheets cover shoulders, elbows/wrists,
pelvis/hips, knees/ankles, and feet.

### Controlled fixtures

The focused gate must accept a valid boundary and reject minimally and clearly
invalid cases for:

- flat/square shoulder, shoulder gap, and shoulder blob;
- oversized hand and overlong arm;
- wrist pinch;
- floating pelvis and excessive hip overlap;
- knee bead and ankle gap;
- reversed side foot direction;
- excessive front toe-in and toe-out;
- excessive dark transverse joint edge;
- incomplete case matrices and nonfinite measurements.

Fixtures are scalar or mask-based and contain no production stable-ID or
screenshot-coordinate exception.

### Repeatability and preservation

The semantic report is run twice and must be byte-identical. The real D3D12
route and review package are run twice from isolated Prompt 27C output roots.
Capture IDs, state metadata, semantic measurements, PPM/PNG bytes, and hashes
must match unless a nondeterministic field was declared before comparison.

Before correction, SHA-256 inventories cover:

- all 314 frozen Prompt 27/27A historical artifacts;
- Prompt 27B final semantic report and repeatability records;
- Prompt 27B final D3D12 runs 8 and 9;
- Prompt 27B review packages 8 and 9;
- the final Prompt 27A regression review retained by Prompt 27B.

No Prompt 27C command writes into those paths.

### Pre-baseline harness correction

The first D3D12 harness candidate required 30 anatomy-owned records per
character. The real side presentation submits 21 anatomy/base-presentation
records because hidden opposite-depth regions are intentionally culled. The
state predicate now requires at least 15 records: one complete visible side
anatomy topology. This is a harness completeness correction, not a visual
acceptance-threshold change. A missing/partial topology below 15 still fails
closed, and the rejected timeout remains preserved in the command record.

The bent-elbow capture predicate was initially `>=30 degrees`. Inspection of
the unmodified authored clips showed that the strongest reusable static
inspection pose is the handshake forearm's `0.42 rad` local bend (about
`24.1 degrees`); a 30-degree predicate could never describe that production
pose. Before freezing the D3D12 anatomy baseline, the evidence-only predicate
was corrected to `>=20 degrees` and the declared key time to `0.55 s`, where
the authored bend is fully established. The production anatomy acceptance
ranges were not changed. A boundary fixture rejects `19.999 degrees` and
accepts `20.000 degrees`.

## Golden and owner-review boundary

Prompt 27C outputs are review candidates. No capture is promoted to an
approved golden until the owner explicitly accepts it. Automated semantic and
pixel acceptance, D3D12 evidence generation, and Codex inspection are
reported separately from owner aesthetic acceptance.

## Implemented production correction

The production bindings now use versioned Prompt 27C male, female, and
component pages. The deterministic source pass:

- replaces square front/profile shoulder corners with bounded sloped torso
  contours without extending the garment-fit envelope;
- softens dark articulation edges and rounds arm/leg endpoints;
- flares the proximal forearm where the inherited source pinched the elbow;
- retains a tapered permanent modest pelvis bridge behind the upper thighs;
- preserves separate anatomy pieces, semantic joints, and source rectangles.

Authored body-part dimensions were retuned per style/view from the
authoritative skeleton and visible source art. Front feet retain the
style-specific production spans (`0.42 m` male, `0.36 m` female); bilateral
`78 degree` local rest rotations resolve to the declared `12 degree` toe-out
after the production transform. The accepted source pass replaces the
inherited profile-shaped front feet with bounded top/three-quarter
silhouettes. Their narrow skin-toned ankle necks resolve to the unchanged
style-specific pivots, while the heel/toe envelope remains compatible with
the existing footwear fit contract. Earlier foreshortened and broad-dorsum
candidates are preserved and were rejected for ankle-width, footwear, or
pixel-overlap failures. The accepted configuration does not change the foot
axis contract, socket, skeleton, planting, garment art, or acceptance
tolerance.

Two ruler corrections were made without changing acceptance ranges. Shoulder
slope and curvature are measured in the submitted torso visual basis, so a
rotated/mirrored production sprite cannot turn source-local contour geometry
into an unrelated screen-axis result. Pixel joint overlap now reports the
longest contiguous occupied projection run rather than the distance between
the first and last occupied projection bins; the prior calculation could
classify two separated antialias islands as one deep solid overlap. The
five-pixel ankle limit is unchanged, and controlled fixtures accept five
contiguous pixels, reject six, and distinguish disconnected two-pixel runs.

No validator threshold was relaxed after the pre-correction declaration.
Style/view-specific values were introduced only where front and profile art
represent distinct semantic silhouettes. Controlled invalid fixtures remain
independent of production IDs and continue to reject every declared failure
class.

## Empirical outcome

The frozen pre-correction report contains 102 cases, 2,450 trace records,
3,788 metrics, and 817 failures. The final and repeated reports contain the
same case/trace/metric counts with zero failures and byte-identical TXT, JSON,
and summary files.

The final production D3D12/DXIL route captures eight body-only states at
640×480: neutral front, both canonical sides, low/high build, extended arm,
bent elbow, and deep knee bend. It uses the existing production queue and
reports zero post-initialization update, submission, queue, and GPU-resource
growth. Two isolated nine-file capture trees and two 18-file review trees are
byte-identical. The final package includes a same-scale before/after sheet and
close-ups for shoulders, elbows/wrists, pelvis/hips, knees/ankles, and feet.

All 314 frozen Prompt 27/27A artifacts remain present and SHA-256 identical.
Prompt 27B's incremental and direct resize tests remain in the 28-test
foundation gate; first-frame viewport reprojection remains distinct from
subsequent world-camera movement, and the 16 px limits are unchanged.

Prompt 27A, Prompt 27B, and Prompt 27C owner/manual visual acceptance remains
`[PENDING OWNER REVIEW]`. Prompt 27D and Prompt 28 were not started.
