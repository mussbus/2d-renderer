# VF-02 — Authoritative Rig-to-Art Registration

## Source status

User-supplied exact execution package in the active Visual Foundation handoff.
This record summarizes the implemented bounded scope and does not replace the
exact request.

## Objective

Make projected rig targets and alpha-visible atlas landmarks own final
production placement for a bounded core anatomy set. Production submission,
VF-01 diagnostics, JSON export, and structural validation must inspect the
same binding evidence.

## Implemented result

- one fail-closed point/segment/frame/mesh-bridge registration contract;
- exact endpoint construction through the production sprite transform;
- independent segment thickness policy that preserves the proximal anchor;
- front, side-right, side-left, reflection, and semantic-identity coverage;
- both arms, forearms, thighs, shins, feet, torso, pelvis, and one face point
  migrated for both styles;
- front base feet use a point-axis contract with one positional ankle target
  and one authored sole-axis orientation constraint; heel/toe/sole landmarks
  remain transformed evidence rather than endpoint targets;
- equipped shoes register their source ankle and sole axis from the registered
  anatomy-foot `PointAxisTarget`, with no independent `+/-78` placement or
  transverse-depth multiplier;
- closed footwear explicitly owns the rendered foot envelope and suppresses
  only covered base-foot pixels while retaining hidden trace evidence;
- registered, compatibility, and transitional authority classification;
- VF-01 schema version 3 registration/visibility export and exact residual
  overlay;
- controlled invalid fixtures for missing, coincident, nonfinite, swapped,
  reflected, degenerate, bypassed, and excessive-residual data;
- real D3D12/DXIL timestamped bundles with same-state clean/debug proof;
- the preserved pre-correction 24-failure Prompt 27B report plus a fresh
  zero-failure corrective report, without rebaselining;
- manual visual acceptance `[PENDING OWNER REVIEW]`.

## Preserved boundaries

Controller, collider, canonical pose, animation, IK, foot planting,
interaction, fixed tick, presentation selection, unified queue, D3D12/DXIL
renderer, atlas resources, and Prompt 27C-R1 presence policy remain
authoritative in their established domains.

The migration does not repaint atlases, convert the wardrobe, add morphology
behavior, generalize topology, retune locomotion, redesign the handshake, or
begin VF-03 or Prompt 28.
